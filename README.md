# Simple Reflex Agent

A simple Python implementation of a **Simple Reflex Agent** in a 2×2 vacuum-cleaner environment.

The agent:
- Cleans a room if it is dirty.
- Moves to the next room if it is clean.
- Visualizes the environment using Matplotlib.

## Tech Stack

- Python
- Matplotlib

 Installation

```bash
uv venv
source .venv/bin/activate
uv pip install matplotlib
```

# Run
```bash
python reflex_agent.py
```
